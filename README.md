# Differential Equations Maple Scripts

## 📌 Overview
This repository contains a collection of **Maple scripts** written to demonstrate how the Maple software can be utilized to solve various types of differential equations. The scripts serve as practical examples for computing solutions, visualizing phase portraits, plotting functions, and exploring other mathematical gimmicks related to differential equations.

## 📂 Repository Structure
The scripts are organized into categorical folders to make it easy to find specific topics:

* **`Introduction/`** * Basic introductory scripts for getting started with Maple and fundamental differential equations concepts.
* **`First_And_Second_Order_Equations/`** * Scripts focusing on solving linear and non-linear first and second-order differential equations.
* **`Systems_of_DEs/`** * Examples of setting up and solving systems of differential equations.
* **`IVPs_and_Phase_Portraits/`** * Tools for solving Initial Value Problems (IVPs) and generating visual phase portraits to analyze dynamical systems.
* **`Mathematical_Models/`** * Applied mathematical modeling scripts representing real-world physical or biological systems using differential equations.

## 🚀 Getting Started

### Prerequisites
To run these scripts, you will need to have [Maplesoft Maple](https://www.maplesoft.com/products/maple/) installed on your machine. 

### Usage
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/CiprianRad/Differential_Equations_Maple_Scripts.git

2. Navigate to the folder containing the topic you are interested in.

3. Open the respective script files in the Maple software.

4. Execute the worksheets to view the symbolic computations, numerical solutions, and plotted graphs.

## 🛠️ Features Demonstrated
Symbolic and numerical solving of Ordinary Differential Equations (ODEs).

Setting up and evaluating Initial Value Problems (IVPs).

2D and 3D plotting of solutions.

Generating phase portraits and vector fields.

Step-by-step mathematical modeling.
